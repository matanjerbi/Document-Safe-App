# Document-Safe-App · כספת

כספת מסמכים אישית לאנדרואיד: מצלמים או משתפים מסמך, האפליקציה קוראת ממנו תאריכי תוקף ומספרים, שומרת אותו מוצפן ומזכירה לפני שהוא פג.

## מה יש בגרסה הזו

- **קליטה:** סורק מסמכים (יישור, חיתוך, ריבוי עמודים), ייבוא תמונות ו-PDF מהקבצים, ושיתוף ישיר לכספת מוואטסאפ, מהמייל או מהגלריה.
- **זיהוי פרטים (על המכשיר, בלי אינטרנט):**
  - דרכון ותעודת זהות ביומטרית: קריאת אזור הקוד (MRZ) שמחזירה מספר מסמך, תאריך תפוגה, תאריך לידה ושם.
  - כל מסמך: תאריכים בפורמטים 12/03/2031, ‏12.03.31, ‏2031-03-12 ו-12 MAR 2031, וזיהוי תוקף, הנפקה ולידה לפי מילים שליד התאריך.
  - מספר תעודת זהות (עם בדיקת ספרת ביקורת), מספרי פוליסה, רישיון ודרכון, וסכום כולל בקבלות.
  - הצעת קטגוריה ושם למסמך.
  - הזיהוי ממלא רק שדות ריקים, ותמיד אפשר לתקן.
- **ארגון:** 12 קטגוריות, "של מי המסמך", תגיות, מועדפים, ארכיון וחיפוש (כולל בטקסט שזוהה).
- **שיתוף:** קובץ PDF אחד או תמונות, עם סימן מים אופציונלי ("העתק לשימוש בבנק בלבד").
- **תזכורות:** בדיקה יומית ב-09:00 והתראה אחת לכל היותר ביום. ברירת המחדל משתנה לפי סוג המסמך (דרכון 90 יום מראש, ביטוח 30 וכו'). אפשר לדחות, ולסמן "חידשתי" כדי להעביר את הישן לארכיון ולסרוק את החדש.
- **ציר תפוגות:** כל התוקפים לפי חודש.
- **אבטחה:** מסד נתונים מוצפן (SQLCipher), קבצים מוצפנים (AES-256-GCM, מפתח ב-Android Keystore), נעילה בטביעת אצבע או בקוד הטלפון, נעילה מחדש אחרי דקה ברקע, וחסימת צילומי מסך. גיבוי אוטומטי של אנדרואיד כבוי.

## מגבלה שכדאי לדעת

מנוע ה-OCR של ML Kit קורא אותיות לטיניות וספרות, ולא עברית. לכן תאריכים, מספרים, MRZ ותוויות באנגלית נקלטים היטב, אבל מילים בעברית כמו "בתוקף עד" לא נקראות. כשאין מילת מפתח, האפליקציה מניחה שהתאריך העתידי המאוחר ביותר הוא התוקף.

## בנייה

כל push ל-`main` מריץ את בדיקות ה-parser, בונה APK חתום ומפרסם אותו ב-Releases.
